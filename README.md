# pyth-overlay-for-x
Chrome extension for real-time Pyth prices on selected X cashtags

## Features
- Prices for popular crypto & equities
- Confidence intervals
- Data from Pyth's public API (Hermes)
- Identification tags for prominent individuals in CT/Fintwit
- No data collection

## Install
From [Chrome Web Store](https://chromewebstore.google.com/search/pyth%20overlay?hl=en-US&utm_source=ext_sidebar)

## Privacy
Open source — no tracking, no data sent anywhere.
